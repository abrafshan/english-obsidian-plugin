# English Learning Plugin for Obsidian

یک پلاگین کامل برای یادگیری لغات انگلیسی با دیکشنری فارسی، سیستم لایتنر، و امکانات پیشرفته

## ویژگی‌های اصلی

### ۱. جستجوی لغت با دیکشنری انگلیسی به فارسی
- تعاریف کامل و چندخطی
- مثال‌های کاربردی
- تلفظ آوایی
- مترادف‌ها
- ترجمه فارسی دقیق

### ۲. ایمپورت فایل اکسل
- پشتیبانی از فایل‌های `.xlsx` و `.xls`
- ستون‌های مورد نیاز: Word, Meaning, Example, Pronunciation, Tags (اختیاری)
- وارد کردن هزاران لغت به صورت یکجا

### ۳. سیستم تکرار با فاصله لایتنر
- ۷ جعبه لایتنر با بازه‌های زمانی قابل تنظیم
- پیگیری پیشرفت خودکار
- نمایش وضعیت هر جعبه در داشبورد

### ۴. مرور تصادفی
- دکمه مخصوص برای انتخاب تصادفی کارت‌ها (پیش‌فرض ۲۰ کارت)
- قابلیت تنظیم تعداد کارت‌های مرور تصادفی

### ۵. هایلایت خودکار در متن
- تشخیص کلمات یادگرفته شده هنگام تایپ
- نمایش رنگی کلمات در ادیتور
- قابلیت غیرفعال‌سازی در تنظیمات

### ۶. صادرات داده‌ها
- خروجی JSON برای پشتیبان‌گیری
- خروجی CSV برای استفاده در اکسل
- کپی خودکار در کلیپ‌بورد

### ۷. جستجوی کارت‌ها
- جستجو بر اساس کلمه، ترجمه یا تعریف
- نمایش سریع نتایج
- امکان مرور مستقیم از نتایج

### ۸. یادآور روزانه
- اعلان خودکار برای کارت‌های عقب‌افتاده
- پیگیری زنجیره مطالعه (Streak)
- هدف هفتگی قابل تنظیم

### ۹. تلفظ صوتی
- پشتیبانی از لهجه آمریکایی و بریتانیایی
- تلفظ فارسی برای ترجمه‌ها
- تنظیم سرعت و زیر و بمی صدا
- تلفظ خودکار هنگام جستجو

### ۱۰. داشبورد جامع
- نمایش آمار کامل
- نمودار جعبه‌های لایتنر
- تاریخچه جستجوهای اخیر
- دسترسی سریع به所有 امکانات

## نصب

۱. پوشه `english-learning-plugin` را در پوشه پلاگین‌های آبسیدین کپی کنید
   - مسیر پیش‌فرض: `<Vault>/.obsidian/plugins/`
   
۲. در آبسیدین به Settings → Community plugins بروید

۳. گزینه "Turn on community plugins" را فعال کنید

۴. پلاگین "English Learning" را پیدا کرده و فعال کنید

۵. داشبورد پلاگین از نوار کناری راست باز می‌شود

## راهنمای استفاده

### افزودن لغت جدید
۱. روی آیکون کتاب در نوار ابزار کلیک کنید
۲. یا کلمه‌ای را انتخاب کرده و از Command Palette استفاده کنید
۳. اطلاعات کامل نمایش داده می‌شود
۴. دکمه "Add to Leitner deck" را بزنید

### وارد کردن فایل اکسل
۱. از Command Palette گزینه "Import Excel file" را انتخاب کنید
۲. فایل اکسل خود را انتخاب کنید
۳. مطمئن شوید ستون‌های Word, Meaning, Example, Pronunciation وجود دارد

### مرور کارت‌ها
- **مرور برنامه‌ریزی شده**: کارت‌های عقب‌افتاده را مرور کنید
- **مرور تصادفی**: تعداد مشخصی کارت تصادفی انتخاب می‌کند
- کلیدهای میانبر: Space (نمایش پاسخ)، 1-4 (درجه‌بندی)

### هایلایت در متن
هنگام تایپ در ادیتور، کلماتی که از قبل یاد گرفته‌اید به صورت خودکار رنگی می‌شوند.

## ساختار ذخیره‌سازی

هر کارت به صورت یک فایل Markdown جداگانه در پوشه "English Learning Cards" ذخیره می‌شود:

```markdown
---
word: example
box: 0
due: 2024-01-15
reps: 0
lapses: 0
created: 1705312345678
---

# example

**Phonetic:** /ɪɡˈzæmpəl/  
**Part of Speech:** noun

## Definition
a thing characteristic of its kind or illustrating a general rule

## Example
This is an example sentence.

## Translation (Persian)
مثال، نمونه

## Synonyms
sample, specimen, instance

---
*Added from English Learning Plugin*
```

## فایل‌های پلاگین

- `main.js` - کد اصلی پلاگین
- `manifest.json` - اطلاعات پلاگین
- `styles.css` - استایل‌های UI
- `data/` - دیکشنری‌های آفلاین
  - `offline-dictionary.json` - دیکشنری انگلیسی
  - `persian-index.json` - ترجمه‌های فارسی
- `engine/mespeak/` - موتور تلفظ آفلاین
